# Colosseum Restoration Rev 15

Cambios principales:
- Historial con selección múltiple de reportes.
- Campo de descuento por lote (%) y botón GENERAR REMITO.
- Remito multipágina: un reporte por página + resumen final.
- Resumen con Carta, Número, Expansión/Set, Versión y costo.
- Total final redondeado hacia abajo a dólares enteros.
- Detalle transparente de descuento y redondeo a favor.
- Condiciones de pago incluidas en la página final.
- Costos de restauración identificados como U$.
- Una puntuación de 1/10 vuelve a 0/10 si se toca nuevamente la primera Poké Ball.
- La base IndexedDB se mantiene en la misma versión y no se elimina ni migra.
