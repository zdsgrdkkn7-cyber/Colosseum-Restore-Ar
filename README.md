# Colosseum Restoration V13

Cambios:
- Encabezado: Cliente + Fecha a la izquierda, IG @colosseum.ar a la derecha.
- Título principal: REPORTE DE RESTAURACIÓN.
- Datos de la carta: Carta, Número, Set, Versión, Idioma, Estado y Precio.
- Eliminado Valor estimado.
- CANTO / BORDE + GENERAL pasa a GENERAL.
- OBSERVACIONES pasa a RESULTADO:
  - campo grande y centrado para MINT / NM / LP / MP / HP / DMG, etc.
  - Observaciones debajo en texto normal.
- PRECIO DEL TRABAJO pasa a COSTO DE RESTAURACIÓN.
- Mayor máscara/espacio alrededor de títulos de panel para evitar que la doble línea los atraviese.
